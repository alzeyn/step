# STEP CODE 🤖 ### Интерактивный учебный сайт — Алгоритмическое мышление, 2 класс ### Версия 2.0 — с Backend (Node.js + SQLite) --- ## Быстрый старт ### Windows Дважды кликни на файл `start.bat` ### Mac / Linux ```bash chmod +x start.sh ./start.sh ``` ### Вручную (любая ОС) ```bash npm install # один раз npm run dev # запускает и сервер, и сайт ``` Сайт: **http://localhost:5173** --- ## Как пользоваться ### Учитель 1. Придумай код класса, например **2А** или **CLASS1** 2. Войди как **Учитель** с этим кодом 3. Раздай код ученикам ### Ученик 1. Открой сайт в браузере 2. Введи своё имя и код класса от учителя 3. Выбери **Ученик** и нажми «Войти» 4. Прогресс сохраняется автоматически! --- ## Что хранит база данных - Имена учеников и учителей - Код класса - Прогресс по каждому заданию - Количество использованных подсказок - Дата и время выполнения --- ## Структура проекта ``` stepcode/ ├── server/ ← Backend (Node.js + Express) │ ├── index.js ← Точка входа сервера (порт 3001) │ ├── db.js ← SQLite база данных │ └── routes/ │ ├── auth.js ← Вход / регистрация │ ├── progress.js ← Сохранение прогресса │ └── teacher.js ← Аналитика для учителя ├── src/ ← Frontend (React) │ ├── main.jsx ← Точка входа React │ ├── index.css ← Глобальные стили │ └── StepCode.jsx ← Весь сайт ├── stepcode.db ← База данных (создаётся автоматически) ├── package.json ├── vite.config.js ├── start.bat ← Запуск на Windows └── start.sh ← Запуск на Mac/Linux ``` ## API эндпоинты | Метод | URL | Описание | |-------|-----|----------| | POST | /api/auth/join | Войти / зарегистрироваться | | GET | /api/auth/me | Проверить токен | | POST | /api/auth/logout | Выйти | | GET | /api/progress | Загрузить прогресс | | POST | /api/progress | Сохранить задание | | GET | /api/teacher/students | Список учеников класса | | GET | /api/teacher/stats | Статистика класса | ## Сборка для публикации ```bash npm run build ``` Папка `dist/` — статика для хостинга. Backend нужно деплоить отдельно (Railway, Render, VPS). --- Разработано в рамках методики формирования алгоритмического мышления у учащихся 2 класса.
